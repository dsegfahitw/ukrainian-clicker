Build a complete mobile-first clicker game called "Українець: Шлях До Успіху" 
(Ukrainian: Path to Success) as a React + TypeScript + Vite + Tailwind CSS web app. 
The game should run fully in-browser with no backend.

---

## TECH STACK
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion (motion/react) for animations
- shadcn/ui components
- localStorage for save/load game state

---

## GAME ARCHITECTURE

### State (all in React useState + useEffect for localStorage autosave):
```ts
{
  // Core resources
  money: number,         // starts at 150 ₴
  health: number,        // 0–100, starts at 75
  reputation: number,    // 0–100, starts at 50
  corruption: number,    // 0–100, starts at 30
  experience: number,    // 0–∞
  level: number,         // 1–100
  
  // Progress
  stage: 1 | 2 | 3 | 4 | 5,  // 1=Village, 2=Town, 3=City, 4=Oblast, 5=Elite
  workClicks: number,
  totalEarned: number,
  
  // Skills (each 0–5 levels)
  skills: {
    farming: number,
    oratory: number,
    bribery: number,
    haggling: number,
    networking: number,
    driving: number,
    accounting: number,
    marketing: number
  },
  
  // Businesses owned
  businesses: string[],   // e.g. ["cafe", "logistics"]
  
  // Passive income per second
  passiveIncome: number,
  
  // Currency unlocks
  unlockedCurrencies: ("uah" | "usd" | "eur" | "crypto")[],
  
  // Inventory
  inventory: { name: string; quantity: number }[],
  
  // Day counter
  day: number,
  
  // Last save timestamp
  lastSaved: number
}
```

Skill tree with 8 skills, each 0–5 levels:

## RANDOM EVENTS SYSTEM
Triggered randomly after work clicks (25% chance). Each event is a modal popup with:
- Title, description text, Ukrainian village illustration emoji
- 2 choices: "Honest Path 😇" and "Corrupt Deal 😈" (or contextual names)
- Each choice affects: money, health, reputation, corruption differently

Implement at least 12 events, including:

1. **Neighbor Needs a Favor** — help get permit via bribe
   - Honest: +rep +50, no money
   - Corrupt: +₴200, +corruption +15, -rep -5

2. **Tax Inspector Visits** — pay taxes or bribe
   - Honest: -₴100, +rep +10
   - Corrupt: -₴50 bribe, +corruption +20, risk of -₴500 fine (20% chance)

3. **Found Money on Street** — keep or report
   - Honest: +rep +15, +₴50 (reward)
   - Corrupt: +₴200, +corruption +5

4. **Sick Coworker** — cover their shift or report them
   - Help: -time (skip passive income for 10s), +rep +20
   - Report: +₴100 bonus, -rep -10

5. **Business Partner Proposes Shady Deal**
   - Refuse: +rep +10, miss profit
   - Accept: +₴500, +corruption +25, -rep -15

6. **Local Gang Demands Protection Money**
   - Pay: -₴150, -rep -5
   - Resist: -health -20, +rep +15

7. **Inflation Crisis — prices up 30%** (forced event, no choice, market prices increase temporarily)

8. **Judge Offers to Dismiss Case** (stage 3+)
   - Pay bribe: -₴1000, +corruption +30, case dismissed
   - Fight honestly: +rep +20, 50/50 outcome

9. **Politician Offers Campaign Support** (stage 4+)
   - Support: +₴2000, unlock political career path
   - Refuse: +rep +5

10. **Viral Social Media Post about you**
    - Positive story: +rep +25
    - Negative leak: -rep -20, +₴300 (tabloid paid you)

11. **Bolt Food Delivery Opportunity** — work extra shift
    - Accept: +₴300, -health -15
    - Decline: rest, +health +10

12. **Army Mobilization Notice** (stage 1-2 only, for humor)
    - "Відкосити" (dodge): +corruption +10, keep playing
    - "Служити" (serve): game pauses for "1 year" (skip 365 days, gain +50 rep, +30 exp)

## STAGE PROGRESSION
5 stages unlocked by total money earned (cumulative):
1. 🌾 Village (Selo) — start, ₴0+
2. 🏘️ Raion Town — ₴1,000 earned total
3. 🏙️ Oblast City — ₴10,000 earned total  
4. 🌆 Kyiv — ₴100,000 earned total
5. 👑 Elite / Oligarch — ₴1,000,000 earned total

On stage up: show animated congratulations modal, unlock new jobs/businesses/events.
Change background image and character emoji to match stage.

---

## PASSIVE INCOME SYSTEM
- Every second, add (passiveIncome × multipliers) to money
- Marketing skill: each level adds +10% to all business income
- Use setInterval in a useEffect
- Show "+₴X/sec" indicator near money bar when > 0

---

## LEVEL / XP SYSTEM
- Gain XP from: work clicks (+5), events (+10–30), business unlocks (+50), skill upgrades (+20)
- Level up formula: XP needed = 100 × level^1.5
- Max level: 100
- Each level up: small celebration animation, possible unlock announcement

---

## SAVE / LOAD SYSTEM
- Auto-save to localStorage every 30 seconds and on every tab change
- On app load: check localStorage for saved game, if found show "Resume Game" modal
- "New Game" button clears save
- Show "Last saved: X minutes ago" in settings

## ADDITIONAL UI COMPONENTS TO BUILD

### ResourceBar component
Props: icon, value, maxValue, color, label
Renders: emoji icon + label + filled progress bar with numeric value

### CorruptionScale component  
Props: value (0–100)
Renders: horizontal gradient bar from green→yellow→red, labeled "Рівень Корупції", 
with skull icon that grows as corruption increases

### EventPopup component
Props: isOpen, event {title, description, choices}, onChoice, onClose
Renders: full-screen semi-transparent overlay + centered card with:
- Large emoji illustration
- Title (Russo One font, uppercase)
- Description text
- Two buttons side-by-side (green honest / red corrupt)
- Animation: slide up from bottom

### SkillsTree component
Grid of skill cards, each showing:
- Skill icon (large emoji)
- Skill name + description
- Level display: filled/empty stars (★★★☆☆)
- "Upgrade ₴X" button (disabled if can't afford or max level)
- Glow effect on affordable upgrades

### StageProgress component
Horizontal progress bar showing % to next stage with milestone labels

### PassiveIncomeTicket component
Floating "+₴X" animations that pop up from the money bar whenever passive income ticks
